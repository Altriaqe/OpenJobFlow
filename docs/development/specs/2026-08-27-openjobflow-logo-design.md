# OpenJobFlow Logo 设计规格

## 目标

为 OpenJobFlow 生成一个可同时用于 GitHub 仓库头像、README 品牌标识和微信公众号头像的纯图形 Logo。Logo 在方形原图与圆形头像裁切后都应清晰可辨，并表达招聘数据趋势分析的项目定位。

## 已选方向

- 图形主题：岗位趋势信号。
- 图内文字：无，不出现 `OpenJobFlow`、`OJF` 或其他字符。
- 风格：扁平、几何、简洁、专业。
- 主要用途：GitHub 与微信公众号共用。

## 图形构成

- 使用三根由低到高排列的圆角数据柱，表示岗位数据规模和市场需求变化。
- 使用一条向右上方延伸的橙色趋势信号线，表示持续采集、分析与趋势输出。
- 图形居中，四周保留充足安全区，圆形裁切不能切断数据柱或趋势线。
- 不加入人物、机器人、简历、公文包、放大镜、货币、公司名称或第三方品牌元素。

## 配色

- 背景：深海蓝。
- 三根数据柱：蓝、亮青、薄荷绿，由低到高依次排列。
- 趋势线：橙色，只作为视觉焦点。
- 保证各元素与背景之间有足够对比度，小尺寸下仍能分辨。

## 视觉约束

- 不使用照片质感或写实场景。
- 不使用复杂 3D、玻璃拟态、强烈发光、密集纹理或细碎装饰。
- 不生成文字、水印、边框说明或 Mockup 场景。
- 线条和数据柱边缘清晰，整体形状不能接近通用刷新图标或单纯分析软件图标。

## 生成方式与输出

- 使用 HeyRoute `gpt-image-2` 文生图接口。
- 请求尺寸：`2048x2048`。
- 质量：`high`。
- 每次请求只生成 1 张；首轮生成不并行创建无关变体。
- 最终 PNG 保存为 `docs/assets/openjobflow-logo.png`。
- 生成过程中不得输出或写入 `HEYROUTE_API_KEY`。

## 验收标准

1. 文件是可正常读取的正方形 PNG，尺寸为 2048×2048。
2. 图内不包含任何文字、乱码、水印或第三方标志。
3. 能清晰看到三根上升数据柱与一条橙色趋势线。
4. 主体完整位于中央安全区，模拟圆形裁切后仍完整。
5. 缩小到 128×128 后，柱体和趋势线仍可识别。
6. 配色符合深海蓝、蓝、亮青、薄荷绿与橙色的约束。
7. 生成结果经人工目视确认后，才决定是否加入 README 或设置为平台头像。

## 迭代边界

如果首张成图偏离图形结构、出现文字或小尺寸不可辨，只针对一个明确问题修改提示词后重新生成。每轮仍生成 1 张，避免同时改变构图、颜色和风格而无法判断改进来源。
